# sicrd-service
Entrega de codigo python para PI1-2026/1

# Requisitos

- Python3
- Pip

# Instalar dependencias (posix)

Criar o ambiente virtual ``python -m venv env``

Habilitar o ambiente virtual ``source env/bin/activate``

Instalar as dependencias ``pip install -r requirements.txt``

# Rodando o projeto

``uvicorn src.main:app --reload``
